# v1.0.0: Operations, Localization & Protection Lens

**Base:** `main` · **Head:** `features/v1.0.0`

## Summary

Open Backup UI v1.0 brings the daily backup health check, investigation, planning, and job creation into a connected Operations experience across Veeam Backup & Replication, Microsoft 365, and Veeam ONE. It adds focused dashboards, storage forecasting, reusable Policy Profiles, eleven bundled interface languages, and consistent navigation and controls.

## What's new

- **Protection Lens:** Overview, Job Operations, Capacity Watch, and Capacity Forecast, with a compact selector, live previews, and a preferred starting view.
- **Storage planning:** retention-aware projections, physical-capacity history, immutability investigation, and backup-hygiene findings.
- **Cached planning evidence:** a server-memory cache scoped to the authenticated source and principal, refreshed every 30 minutes in the background for saved VBR connections. Opening the view uses cached evidence, while manual Refresh bypasses the interval. Transient failures retain the last available snapshot and its original collection time with a visible failure state.
- **Jobs & Policy Profiles:** a guided VMware/Hyper-V job builder with payload review and reusable retention, guest-processing, and schedule profiles.
- **Connected investigation:** workload errors, session and task logs, API-supported retry chains, restore-point details, protection topology, and workload resilience.
- **Protected Data:** preserved HexMap views with workload names, clearer RPO colors, smarter time controls, and cached loading.
- **Operations across the platform:** refreshed infrastructure and inventory, Microsoft 365 dashboards and inventories, Veeam ONE alarms and reports, and administration views. Existing data and actions remain available.
- **A consistent interface:** global search with previews, expandable filter rails, sortable grids and dates, compact controls, consistent breadcrumbs, and phone navigation.
- **Theme customization:** Operations plus Glass Ocean, Glass Forest, and Glass Aurora, with configurable fonts, colors, density, and live preview.
- **Localization:** English, Spanish, German, Russian, French, Brazilian Portuguese, Simplified Chinese, Japanese, Italian, Korean, and Hindi, with browser detection and a saved language preference. Migrated widgets, counts, statuses, filters, descriptions, loading messages, and VBR/Microsoft 365 investigations use bundled catalogs and localized date/number formatting.
- **Connection showcase:** screenshot-led feature previews on `/connect`, with translated captions, manual selection, pause/play controls, and reduced-motion support.
- **Application settings and HTTPS:** a language/region panel and an optional managed HTTPS launcher, with certificate inspection and validated PEM replacement without restarting the application. Existing reverse-proxy deployments remain supported.

Localization also covers the active Backup Copy and Entra ID creation flows, Policy Profile editors, repository details, restore-point calendars, workload/task drawers, and known application-authored diagnostics. AI health summaries request their narrative in the selected language. Resource names, API values, vendor logs, and custom section names retain their original values. The [coverage notes](https://github.com/jorgedlcruz/open-backup-ui/blob/features/v1.0.0/docs/i18n.md) identify the migrated areas and remaining legacy boundaries.

## Upgrade and behavior notes

- Back up the persistent `data/` directory and its encryption key before upgrading. Policy Profiles and capacity history use local persistent storage.
- Capacity collection requires a persistent server and writable storage. Physical forecasting requires at least three daily readings spanning 48 hours.
- Full planning refresh runs separately from the 15-minute physical-capacity collector and continues with the browser closed. The memory cache rebuilds after a server restart; browser-only sessions cannot refresh unattended. `CAPACITY_COLLECTOR_ENABLED=false` disables both background tasks while leaving manual planning refresh available.
- Forecasts and hygiene findings are advisory. They do not delete backups or change retention. Applying a Policy Profile copies its settings into a new job; later profile edits do not modify existing jobs.
- Feature availability follows API version, permissions, and returned evidence. Missing evidence remains explicit.
- Source archives include application source, the dependency lockfile, public images, and documentation; install dependencies with `npm ci` after extraction. Saved connections, runtime `data/`, private certificates, local environment files, `node_modules`, and build caches are excluded.
- Managed HTTPS is opt-in with `npm run start:https`. Persist its certificate directory, configure a dedicated HTTPS administration token for replacement, and retain deployment access controls: HTTPS does not add an application login.
