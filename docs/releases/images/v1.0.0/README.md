# v1.0.0 documentation images

All 43 numbered images are included in the release source ZIP and referenced by the [visual guide](../../v1.0.0-gallery.md) and [capture checklist](../../v1.0.0-screenshots.md). The [release notes](../../v1.0.0.md) place these features in context. Images 39–43 cover Glass Ocean, Glass Forest, Glass Aurora, the Spanish interface, and the connection-page showcase.

These are reviewed application screenshots, not raw chat attachments. Passwords, API keys, tokens, saved connection files, and license identifiers are excluded. Lab object names and addresses remain visible. The gallery identifies development captures that predate the final navigation/filter refinements.

Images use high-quality WebP to keep the portable Git repository small. New captures should use the same numbered filenames and be reviewed before committing.

The application also includes its showcase images in `public/images/connect/`. These are packaged with the source so the connection-page carousel works after extraction and installation; it does not fetch screenshot assets from a third-party host. Captions are localized, while screenshot pixels retain the language of the capture.
