## Installation and build baseline

The following baseline was recorded before the later localization and HTTPS additions, using Windows, Node.js 22.13.1, and npm 10.9.2. It verifies the corrected installation dependency set at that point.

## Installation issue and correction

The original release candidate was installed with `npm ci --legacy-peer-deps` before its tests and build passed. That bypassed npm peer-dependency validation and did **not** establish that ordinary `npm install` worked. A fresh checkout reproduced the user's `ERESOLVE` error: React 19.1.0 did not meet the installed AI SDK React adapter's peer range. Unused Tremor and legacy map dependencies also required React 18.

The correction removes the unused AI React adapter, Tremor, legacy map package/types, and the unreferenced old alarm-map component. Active AI integrations, native alarm geography, and HexMap views remain in place. React and React DOM are aligned at 19.1.10, Next.js and its ESLint configuration at 15.5.28, and compatible advisory fixes are locked. A PostCSS override selects 8.5.32 within the existing major version. Optional identity fields are now explicit in their schema to retain Unknown handling with the updated validation library.

CI, the release workflow, the Dockerfile, and setup instructions now use normal `npm ci`. CI also runs `npm ls --all` to catch invalid peer dependencies.

## Scope

The 27 October application checks verify the regression suite, TypeScript, targeted lint, a fresh production build, documentation links, screenshot presence, and selected browser flows on Windows. The earlier installation baseline verifies clean dependency installation and selected startup/HTTP paths. These checks do not certify every supported platform version, every API action, or container behavior. Linux CI is configured for Node.js 20 and 22; its results require publishing the final branch and running the workflow. Audit results are a point-in-time dependency check, not a security certification.
